由你真實 caption 得出嘅 3 個重要結論：

① Caption 係最強來源 —— 你嗰兩段字有齊店名、完整地址、日期、時間、菜式。比 Google Maps 仲多資料（Maps 冇圖冇內文）。
② 要分「實際位置」同「品牌來源」 —— 「長岡博多天婦羅」實際喺銅鑼灣。如果傻更更見到「博多」就歸類福岡，你朋友去到銅鑼灣撲空。呢個 bug 一定要避。
③ 日文地址要識拆 —— 〒823-0003 福岡縣宮若市本城65-1 → 郵區 823-0003、縣 福岡縣、市 宮若市、町名番地 本城65-1，可以直接餵去地圖 API 轉座標。

⚠️ 而家嘅規則是手寫 rule-based（正則 + 詞典）。咁做解釋性好、免費、快。之後可以加 LLM 做 fallback 處理規則 miss 嘅情況。
